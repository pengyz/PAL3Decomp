# 目标分解论证（立场 D · 只出论证，未改产品文件）

**主张**：「字节一致」是全或无的二元目标，实际是三层——T1 精确字节 / T2 语义等价 / T3 功能等价。faithful remake 的验收线应为 **T2**，T1 降为边界定点证明。

## 核心论点

1. **现有「字节一致」自身已是分层度量**。L1 判据自带三条 don't-care：截断、长度、重定位 4 字节不比。实测（`data/status/s4_baseline.json`）：L1 7446 字节中重定位覆盖 1968（26.4%），其中被掩盖的双侧真差异 1366 字节（18.3%）；182 例中 179 例编译产物长于原函数（1903 尾字节 NOP 被截断隐藏）。⇒ 当前所谓 T1 已是「语义等价 + 编译器近似」，再要求纯 T1 与本仓自身度量矛盾。
2. **T2 已覆盖 remake 的全部价值来源**。remake 的价值 = 玩家可观察行为（画面/脚本/数值/时间线）。业界 faithful-remake 实践（行为规格提炼→移植→trace/截图差分→ratchet+白名单）本质就是 T2 定义；换语言重写在字节维度恒不成立，却公认 faithful。T1 是「证明理解」的手段，不是 remake 的目标。
3. **边际收益递减已被门禁史证实**。S2 错误 1720→1302（T6→T146）后平台化；L1 在 T58–T67 六连迭代冻结于 135/136；快赢（T143–145 单日 +4）收割后再度停滞。投入侧 109 工具 · 111 文档（77 gotcha）· 214 cpp；剩余大头是编译器考古而非游戏语义：hexrays_limit 42.5%（政策不修）、C1003 截断单元 2×102 条遮蔽、reloc 8251 站点/7759 未对齐、78 unresolved_synth——对玩家行为零贡献。
4. **目标分层可砍掉整块必做集**：vc6 mangler 全覆盖、COMDAT//Gy NOP 对齐、调整 thunk、reloc 逐站对账整体降为选做；T1 仅保留在外部契约边界。每 1% L1 的成本以 gotcha 增速与平台期为证，远超同等工作量投在行为覆盖上的收益。

## 量化证据

- L1 ≈ 17.2%（三限定）；match_L1=194/1303 符号、partial=773（长尾 4:1）— `s4_baseline.json`
- L1 隐藏差异 18.3% 字节；179/182 函数尾部被截断隐藏 — `gotcha_l1_reloc_dontcare_three_qualifications`
- 错误地板 ≈1302，其中 hexrays_limit 42.5% 不修、annotation_fix 33.6% — CLAUDE.md 修复优先级
- T1 专属考古存量：reloc 8251 站点（7759 未对齐）、synth 78 — `s4_baseline.json`

## 承认的反驳

1. **边界场景必须 T1**：mod 按地址 hook、存档格式、内存修改器、speedrun RNG 操纵（依赖精确指令序列）、导出/vtable 即 ABI。⇒ 反驳成立；主张「边界 T1 + 内部 T2」，而非全域 T1。
2. **T2 不能证明等价**（抽样、状态空间爆炸、UB）；T1 是可判定强证明。⇒ 成立；故 VM/RNG 核心保留 T1 定点，差分必须配可审计 ratchet+白名单。
3. **matching decomp 有独立价值**（可信度、工具沉淀，且快赢仍在）。⇒ 承认；但应作独立科研线管理，不阻塞 remake 主线，不作全域验收门。

## Tier 2 判据（可执行）

- **T2-F 函数差分**：输入域 = 脚本语料 ∪ 边界值 ∪ 覆盖率引导 fuzz；比对（返回值, 语义状态字段）；规范化后逐字段相等（指针→对象 id 表、padding 归零、浮点 ULP≤2）。
- **T2-VM 状态机等价**：同 SCE 脚本的 opcode trace + 栈/寄存器语义值逐步等价（允许 PC/地址不同）。
- **T2-Frame 渲染等价**：固定脚本逐帧截图 diff，逐通道 Δ≤1/255 或感知哈希同，屏蔽时间水印。
- **T2-IO 存档等价**：同操作序列 → 存档字节精确相等（此域保留 T1 强度，属外部契约）。
- **处置与出口**：差异 = 修复 或 白名单（理由+复核人），只减不增；主 KPI 由 L1% 换为**行为覆盖率**（被差分执行到的原函数占比）。
