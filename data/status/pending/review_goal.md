# 目标分解论

现状：单一「字节一致」把三种难度压成一个判据。L1 17.2%（三限定后：截断比较、编译短即 partial、重定位 4B don't-care）已进入高成本区，建议分层，Tier 2 为**主目标**。

## Tier 定义

- **Tier 1 精确字节匹配**：与 PAL3.exe 逐字节相同（现行 L1 + 三限定），绑定 MSVC 6.0 偶然性：vtable/COMDAT/模板特化/CRT 边界。
- **Tier 2 语义等价（建议主目标）**：同输入同状态下副作用序列、可见状态、存档字节、SCE VM 轨迹一致；字节可不同。
- **Tier 3 功能等价**：玩家可感知结果一致，内部表示自由。

## 论点 1: Tier 2 已足够（证据）

1. **消费端是行为**：重制版不产出 MSVC 6.0 字节，反编译产物的用途是行为规格；Tier 1 多出的信息（指令选择/寄存器分配）无消费方。
2. **字节一致是语义正确的代理而非目的**（「编译不可逆，我们在再创作」）。字节同 ⇒ 行为必同，是强校验；差分测试同样强时代理可替换。

### 论点 2: Tier 1 边际收益递减

17.2% 后剩余 partial 的差异成因是布局链疾病（145 多继承 + 59 多态类漂移）、CRT 边界、vtable/COMDAT、优化形态——全落在 Phase 2 手工逐字节 fix，每 1% 成本与前 17% 不同量级。且 L1 自带盲区（重定位覆盖 27.65% 字节，隐藏差异 19.24%），继续堆字节收益有限。

### 论点 3: 分层大幅降工作量

约 83% 非 L1 函数退出 Phase 2 grind，验收改为行为测试；Tier 1 只留白名单（存档序列化、SCE VM 核心、校验和/反篡改、时序敏感），总量百级。省下的力量投布局/语义标注，抬高 Tier 2 覆盖。

## Tier 2 判据

1. **差分执行**：原版作 oracle（模拟器/受控回放），同输入比对状态快照、SCE 轨迹、存档、I/O；浮点位级一致（x87 可复现），例外逐条豁免。
2. **函数级契约测试**：固定入口状态 → 断言出口状态与副作用序列；通过集棘轮，未覆盖路径显式记账。
3. **白名单升级**：白名单内加跑 Tier 1 字节比对（现行 `match` 作该子集裁判）。

## 承认的反驳

1. **oracle 依赖**：Tier 2 以原版为裁判；若要求无 oracle 的正确性证明，Tier 1 不可替代。
2. **覆盖盲区**：未测路径会静默分叉，字节一致在构造上排除之；缓解 = 棘轮 + 覆盖账，不声称风险为零。
3. **工具链敏感场景**：反篡改/校验和/崩溃地址依赖/speedrun 验证必须 Tier 1——白名单已覆盖，但「白名单画错 = 漏检」须承认。
4. **Tier 1 是最强语义证据**：partial 字节 diff 是布局错误的直接证据，annotation 裁判依赖它。故 Tier 1 降为**诊断工具**而非验收目标，不删除。

## 结论

Tier 2 为验收主目标，Tier 1 为白名单 + 诊断裁判，Tier 3 兜底。语义要求不降，只把「字节复刻 MSVC 6.0」从产品目标降为可选精度；代价是白名单纪律与覆盖记账，远低于全量 Phase 2 grind。
