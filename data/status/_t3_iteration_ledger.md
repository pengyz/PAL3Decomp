## 一、本迭代裁决（Decisions）

### D1 · T17 反证「漂移型 0 ≠ 归属错 0」（口径修正）
- **背景**：T17 诊断发现「误归属 → vptr → 全员漂移」当前 0 例（11 个 virtual-injected 类全部 layout 一致）
- **但**：`UIPostUpdate`/`SRWR` 是**真归属错**（A 级 objdump 证据：`UIPostUpdate@0x41EB80` 首条 `mov eax,ds:0xc116ec` 读全局，无 `mov esi,ecx` ⇒ 自由函数被误归属；`SRWR@0x52F2E0` 读 `[esi+0x268]` 超类体）
- **裁决**：**「漂移型归属错 0 例」不等于「归属错 0 例」** —— 两种口径必须分开
- **教训**：否定结论必须附精确命令 + 统计口径（不能把"漂移型 0"当成"归属错 0"）

### D2 · T18 最小修双簇合并落地（NewTexture + _TEB）
- **背景**：T17 ROI 排序定位最高 ROI 簇 = NewTexture 参数形 + _TEB include
- **落地**：`fe2c9a59a` 一次提交两簇，**3 单元回绿**（CEffQuad / UI3DCtrl / CEffGrid）
- **效果**：S2 112→**115** · L1 104→**109**（+5）
- **理由**：低风险高确定性，两簇都是 include/annotation 层小改，verify 简单

### D3 · T19 C2440 逐个裁决（3 修 2 回退）
- **背景**：T17 预测 C2440 逐个修可 +10 S2；T19 实测：**3 修 2 回退**
- **裁决**：**逐个 A 级证据裁决**，不能批量修（禁猜测性修改）
- **效果**：S2 115→**117** · L1 109→**113**（+4）—— 比预期保守（预期 +10，实测 +2 绿单元）
- **教训**：C2440 是"聚合错误码"，实际是**多种机制**（lvar 退化 / 类型不匹配 / 调用约定）；批量修必翻车

### D4 · T21 this 槽丢参不改名（Block 案限缩）
- **背景**：T20 发现「同名全局遮蔽 = 静默语义腐蚀」；T21 修 this 槽丢参
- **裁决**：**不改名**（保守）——Block 案只修丢参，不动名字
- **效果**：CCBSkillWindow 回绿（S2 117→**118** · L1 113→**115**）= 迭代 3 峰值
- **教训**：**限缩优于通吃**（一次只修一个变量，避免误判）

### D5 · T22 F1 blocker → T23 根治（复核链 t22→t23→t24）
- **背景**：T22 复核发现 F1 blocker（dtor 丢参 `params[1+]` 裸丢）
- **裁决**：T23 **repair-round-2** 根治 F1 + **台账限缩**（非阻塞观察记录不阻塞主线）
- **T24 pass**：验证 F1 已根治 + 非阻塞观察（`archive/iter3_t18/` 目录名误导来源）
- **教训**：**复核链的每一环都要留下可复核的台账**，让后续 agent 能看到"哪些已根治、哪些只是观察"

### D6 · T22-F6 明确指出 CLAUDE.md 陈旧（112/209·1434·104 vs 实况 118/209·1383·115）

## 二、本迭代教训（Lessons）

### L1 · 零残留类声称必须附精确命令
- **症状**：T22 声称"某类零残留"但未给 grep/audit 命令，T23 复核发现实际有残留
- **规则**：**任何"零/清空/根治"类声称必须附可复核命令**（grep · audit · probe 等）

### L2 · 通吃限缩（T21 Block 案）
- **症状**：想一次修"this 槽丢参 + 改名"两变量
- **裁决**：**限缩到只修丢参**，改名挂账
- **规则**：**一次只动一个变量**，避免多变量混杂后误判因果

### L3 · 漂移型 0 ≠ 归属错 0（T17 口径）
- **症状**：T17 报告"漂移型 0 例"被误读成"归属错 0 例"
- **规则**：**否定结论必须附精确命令 + 统计口径**；两种口径分开计

### L4 · 静默语义腐蚀（T20 发现）
- **症状**：同名全局遮蔽导致字节级不可见的语义改变
- **沉淀**：`docs/knowledge/`（`8c0ba06ca`）—— **字节级不可见的语义腐蚀比可见 bug 更危险**
- **规则**：涉及同名符号时必须做遮蔽风险扫描

### L5 · 复核链台账限缩（T23）
- **症状**：T22 复核发现多项，一次性标注"全部待修"
- **裁决**：**T23 分级**（F1 blocker 修 · 非阻塞观察记录不阻塞）
- **规则**：**复核发现必须分级**，blocker 立即修，观察记录不阻塞
