PAL3 反编译项目 - 文件结构
================================================================================

根目录文件
----------
  README.md              - 项目首页（快速开始、概览）
  CLAUDE.md              - 项目详细说明（工作流程、规则）
  QUICK_START.txt        - 配置完成速查表
  CMakeLists.txt         - CMake 构建配置

构建脚本
--------
  setup_env.bat          - 编译器环境配置脚本
  build.bat              - 主构建脚本
  test_build.bat         - 快速测试编译
  check_toolchain.py     - 工具链检测脚本
  run.py                 - 项目管理工具

配置文件
--------
  local_config.json      - 本地配置（游戏路径）
  requirements.txt       - Python 依赖

源代码目录
----------
  src/
    ├── topo/            - topo.dll 源代码（7 文件，2,340 行）✅
    ├── gbengine/        - gbengine.dll 源代码（待创建）
    └── pal3/            - PAL3.exe 源代码（待创建）

反编译数据
----------
  asm/
    ├── gbengine/        - 3,213 个函数的 JSON 数据
    ├── topo/            - 414 个函数的 JSON 数据
    └── _*.json          - 汇总信息

头文件
------
  include/
    ├── pal3.h           - 主头文件
    ├── pal3_config.h    - 编译器配置
    ├── pal3_types.h     - 基础类型
    ├── pal3_structs.h   - 结构体定义
    └── pal3_globals.h   - 全局变量

文档
----
  docs/
    ├── TOOLCHAIN_SETUP.md       - 工具链使用指南 ⭐
    ├── SETUP_COMPLETE.md        - 配置完成报告
    ├── install_msvc.md          - MSVC 安装教程
    ├── compiler_setup.md        - 编译器技术细节
    ├── unpacking.md             - PAL3.exe 脱壳指南
    ├── community_structs.md     - 社区逆向的结构体
    ├── sce_opcodes.md           - SCE 脚本操作码
    └── file_formats.md          - 文件格式文档

工具
----
  tools/                 - 自动化脚本（待添加）

构建输出
--------
  build/                 - CMake 构建目录（git 忽略）
    ├── topo/            - topo.dll 构建
    ├── gbengine/        - gbengine.dll 构建
    └── pal3/            - PAL3.exe 构建

================================================================================

文档层级关系
------------

新用户入口：
  README.md → QUICK_START.txt → docs/TOOLCHAIN_SETUP.md

编译器安装：
  docs/install_msvc.md → docs/compiler_setup.md

项目工作流程：
  CLAUDE.md → docs/unpacking.md → docs/file_formats.md

结构体参考：
  include/pal3_structs.h ← docs/community_structs.md

脚本工具：
  check_toolchain.py  - 环境检查
  setup_env.bat       - 配置编译器
  build.bat           - 编译目标
  run.py              - 项目管理
