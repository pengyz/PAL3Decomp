**进度贡献:** 10% → 25%

```
src/pal3/ui/
```

**Task 1: UI 基础框架 (Week 1)**

**Task 2: 基本控件 (Week 1-2)**

**Task 3: 菜单系统 (Week 2-3)**

- 系统菜单（保存、读取、设置、返回）

**Task 4: 对话系统 (Week 3-4)**

- 选择框（分支选择）
- 消息框（系统消息）
- 对话历史

**Task 5: HUD 系统 (Week 4-5)**
- 生命值/法力值条
- 角色头像

**Task 6: UI 动画和特效 (Week 5-6)**

## Phase 4: 战斗系统 (2 个月)

**目标:** 实现完整的回合制战斗系统

**工期:** 2 个月  
**函数数:** 800-1200 个  
**进度贡献:** 25% → 50%  
**重要性:** ⭐⭐⭐⭐⭐ (核心玩法)

### 文件结构
```
src/pal3/battle/
├── battle_manager.cpp          # 战斗管理器
├── battle_flow.cpp             # 战斗流程控制
├── turn_manager.cpp            # 回合管理
├── action_queue.cpp            # 行动队列
├── skill_system.cpp            # 技能系统
├── skill_database.cpp          # 技能数据库
├── ai/
│   ├── ai_controller.cpp       # AI 控制器
│   ├── ai_enemy.cpp            # 敌人 AI
│   ├── ai_partner.cpp          # 伙伴 AI
│   └── ai_behavior.cpp         # AI 行为树
├── damage_calc.cpp             # 伤害计算
├── buff_system.cpp             # Buff/Debuff 系统
├── battle_ui.cpp               # 战斗 UI
└── battle_effects.cpp          # 战斗特效
```

### 主要任务

**Task 1: 战斗框架 (Week 1-2)**
- 战斗管理器
- 战斗状态机（准备、回合、结算、结束）
- 战斗场景加载
- 角色和敌人初始化

**Task 2: 回合制逻辑 (Week 2-3)**
- 回合管理器
- 行动顺序计算（基于速度）
- 行动队列
- 回合开始/结束事件

**Task 3: 技能系统 (Week 3-5)**
- 技能数据结构
- 技能数据库（~200 个技能）
- 技能执行逻辑
- 技能目标选择
- 仙术、武技、合击
- MP 消耗和冷却

**Task 4: 伤害计算 (Week 5-6)**
- 伤害公式（攻击、防御、属性克制）
- 暴击计算
- 命中/闪避
- 属性相克（五行）
- 伤害显示（飘字）

**Task 5: AI 系统 (Week 6-7)**
- AI 控制器
- 敌人 AI（攻击选择、目标选择）
- 伙伴 AI（自动战斗）
- AI 行为树
- 难度调整

**Task 6: Buff/Debuff 系统 (Week 7)**
- Buff 管理器
- Buff 类型（增益、减益、持续伤害）
- Buff 持续时间
- Buff 叠加规则

**Task 7: 战斗 UI (Week 8)**
- 指令菜单（攻击、技能、物品、逃跑）
- 角色状态显示
- 敌人信息显示
- 技能选择界面
- 战斗日志

**Task 8: 战斗特效 (Week 8)**
- 技能特效
- 伤害特效
- Buff 特效
- 角色动画

### 验收标准
- [ ] 能进入和退出战斗
- [ ] 回合制流程正确
- [ ] 所有技能能正常释放
- [ ] 伤害计算准确

## 实施建议

### 并行开发
某些系统可以并行开发：
- UI 系统 + 战斗系统（不同开发者）
- 场景系统 + 存档系统（不同模块）

### 迭代开发
每个系统采用迭代方式：
1. 核心功能（1-2 周）
2. 扩展功能（1-2 周）
3. 优化和修复（0.5-1 周）

### 测试驱动
每个系统完成后立即测试：
- 单元测试（函数级）
- 集成测试（系统级）
- 功能测试（玩家视角）
