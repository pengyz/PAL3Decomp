## 1. 现状（读码实测 ✓）

**同一个 `stage3_cleanup.py` 里有两套解析器、两种调用约定**：

| | ① AST 层（`:578` `_resolve_vftable_calls_ast` ✓，**先跑** ✓）| ② legacy 正则层（`:1072 / 1104 / 1132` **三次顺序遍历** ✗，后跑 ✗）|
|---|---|---|
| 输入 | tree-sitter 语法树 ✓ | 纯文本 ✓ |
| 覆盖 | 全部语法形态（含 `.` 与 `[...]` ✓）| 只认 `\w` + `->` ✗ |
| 槽位来源 | `store.method_sigs` + 注解 ✓ | `store.struct_vtables` ✓ |
| 失败时 | 合成 **stub** ✓ | **原样保留** ✗ |

**发射的调用有两种语义** ✗：

```cpp
// ③a 已解析 ⇒ 成员调用语义 ✓
obj->Method(args_减去self);
// ③b 未解析 ⇒ stub ⇒ **自由函数语义，对象当第 1 参** ✗（:494 注释原文："stub 的形参表要把对象指针放首位"）
stub_decl:  Ret Method(void *obj, args...);
stub_call:  Method(obj, args...);
```

**规模**（生成物实测 ✓）：`__vftable` 残留 **277** ✓ · C2065 **100** ✓ · C2227 **226** ✓ · 总错误 **2150** ✓ · S2 **75/205** ✓ · L1 **34** ✓

## 2. 五个问题（按危害排序）

**P1 · 同一语法位置两种调用约定** ✗✗（最根本）
resolved 走**成员调用** ✓；stub 走**对象当第 1 参** ✗ ⇒ **不能同时正确** ✓。

**P2 · 一个"承重 bug"** ✗✗（**这是修不动的直接原因** ✓）
`_drop_self_arg(args, obj)`（`:610` ✓）用 **owner 原文**匹配第 1 实参 ✓；
owner 被截断（P3 ✗）⇒ **匹配不上** ⇒ **self 实参没被丢掉** ✗ ⇒ **恰好满足 stub 的"对象第 1 参"约定** ✓
⇒ **P3 的 bug 在替 P1 的设计缺陷兜底** ✓✓ ⇒ 修 P3 就抽掉兜底 ⇒ **C2660** ✓
**实测（两次，独立）**：
| 尝试 | 改动 | 结果 |
|---|---|---|
| 1 | legacy 层四处 owner 模式 | 2150 → **2167** ✗（C2660×15 ✗）|
| 2 | AST 层两处 owner 提取（**只改 owner** ✓）| 2150 → **2167** ✗（C2660×10 ✗；C2065 100→96 仅赚 4）|

**P3 · owner 提取是"无锚点正则"** ✗（8 处同款 `(\w+(?:\s*->\s*\w+)*)` ✗）
不认 `.` 与 `[...]` ✗ + **无锚点** ✗ ⇒ 对 `this->A[2].B[0].pDebugTex->__vftable` **从 `pDebugTex` 处起匹配** ✗。
**职责不同** ✗：**2 处在 AST 层**（`:476` named-slot / `:500` raw-offset ✓ —— **决定发射文本** ✓）；
**6 处在 legacy 层**（`:90 / 1078 / 1110 / 1138 / 1165 / 1189` ✗ —— **决定哪些调用被匹配** ✗）。
**对照单测**（纯函数 ✓）证明修复本身精确 ✓：旧 `owner=pDebugTex` ✗ → 新 `owner=this->me_Role[2].m_RoleAttCng[0].pDebugTex` ✓；简单成员病例两版**完全一致** ✓。

**P4 · 两层重叠、优先级未定义** ✗
层①先跑 ✓、层②后跑 ✗ ⇒ 同一调用可能被两层先后改写 ✓ ⇒ 行为依赖**文本形态的偶然性** ✓。

**P5 · "self" 判定靠原文逐字比较** ✗
`a.replace('&','').strip() != obj` ✓ ⇒ 对 `(Class *)obj` ✗、空白差异 ✗ 都不稳 ✓。

## 3. 重构目标架构

**一句话**：**一套解析器 · 一份 owner 语义 · 一种调用约定** ✓

| 组件 | 设计 |
|---|---|
| **R1 解码器**（唯一 ✓）| 只用 **AST** ✓；返回**结构化**结果：`owner_path`（**访问器列表** ✓：`[('this',None),('me_Role',2),('m_RoleAttCng',0),('pDebugTex',None)]` ✓ —— **不是字符串** ✗）· `slot` · `args`（AST 节点 ✓）· `ret/params` 提示 ✓ |
| **R2 owner 渲染器**（唯一 ✓）| `render_owner(path) -> str` ✓ —— **全仓唯一**产生 owner 文本之处 ✓（`.` / `->` / `[...]` 一次解决 ✓）|
| **R3 统一约定** ✓ | **成员调用语义** ✓：`obj->Method(args_减去self)` ✓ ⇒ **stub 必须成员兼容** ✗ ⇒ **stub 声明不再前置对象指针** ✗，改为 `Ret Method(args...)` 并使该 stub 成为**该对象类型的成员/接口方法** ✓ ⇒ **P1 与 P2 同时消解** ✓✓ |
| **R4 self 判定结构化** ✓ | 比较 `owner_path` 与第 1 实参的**解码结果** ✓（而非字符串 ✗）|
| **R5 退役层②** ✓ | 把层②**独有**形态并入 R1 ✓ 后**删除三次正则遍历** ✗（277 处残留 = 覆盖度普查 ✓）|
