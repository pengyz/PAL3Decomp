# gotcha：显式类型铸不是恒等变换（类值/指针链 RHS 的铸形陷阱）

**日期**：2026-09-29（批 5 `cast_reg_assignments` 接线回退教训）
**症状**：给 `reg_X = <rhs>;` 无条件补 `(unsigned long)(<rhs>)` 显式铸（设计依据="原码隐式转换
的显式化，整型 RHS 恒等铸"）——实测真新增 15（UIScene +13 C2227/2228·PAL3 +2 C2679·
ScriptVM 60→102 级联），零回归门破，接线撤回。

## 为什么"恒等"前提错

| RHS 形 | 隐式赋值 | 显式 `(unsigned long)` 铸 | 恒等？ |
|---|---|---|---|
| 标量（int/bool/\_\_int64/浮点/指针 32 位）| 截断转换 | 同截断 | ✓ |
| **类/结构体值** | **编译错**（C2679/C2440）| **铸形错**（C2440 'type cast'）| ✗ 错误形态变 |
| **指针链成员访问** `x->m_a->m_b` | 成员访问语法完整 | `(unsigned long)(x->m_a->m_b)` 外层包裹改**表达式结构** | ✗ 破坏链 |
| 逗号表达式 `a, b` | `(reg=a), b` | `(reg=(a,b))` **改赋 b** | ✗ 语义反转 |
| `==` 比较（正则误捕）| — | 语法级破坏 | ✗ |

**核心**：显式铸只对**标量**恒等；对类值/复合表达式改变语法结构与重载决议——
"补铸=显式化隐式转换"的推理**仅在 RHS 为标量表达式时成立**。

## 可检查规则
- 任何"补显式铸"变换前，先证明 RHS 全域为标量表达式（型判别），否则分流/不动。
- 类值 RHS（成员读出类类型/函数返回类类型）**永不铸**——那是型错不是铸缺。
- 指针链/逗号/比较/链式赋号形 RHS 一律保守不动。
- 生产实效验证必须过零回归门（本轮 reviews 三连绿但管线一跑即破——
  **review 的静态面 ≠ 管线实效面**，工具批的验收必须含一次 codegen 实测）。
