# 全局变量实况分类——2K extern 里只有 ~300 真变量的判据与坑

事实：globals.h 2,232 extern 经五维分类（串指纹/A 级锚 span/static 块/写点访问形态/命名形态）
定谳：**真·可变全局 271 + 锚对象本体 38 ≈ 309 真变量/对象（13.8%）**；其余是串字面 559、
常量表 656、指针表 155、表片段 57、static 59、待证。"游戏不可能有 2K 全局"的工程直觉成立——
多出来的是字面量/表/链接器产物/对象内部访问被误立为独立全局。

**为什么：** 三层污染源——①字面量（VC6 串池/常量表被逐条立为 extern）②表片段（表基址经
[base+idx] 寻址、片段地址永不绝对现身 ⇒ per-VA xref=0 假象，**零引用≠可删**）③大容器内部
（A 级锚对象 span 内的地址被区间臆造立为全局）。另两个实测坑：**锚对象本体会被"内部"判定
误收**（`lo <= va` 把对象自己算进自己肚子里——必须 `lo < va` 严格内部+本体单列）；
串指纹函数签名是 `(buf, min_run)` 取**字节切片**，传 (data, offset) 会恒零命中。

**何时使用：** 任何"全局太多/extern 清理"类工项——先跑 tools/global_reality_scan.py 五维分类
再谈处置；发射分区（GAME STATE 段独显真变量面）**只动 header、globals.cpp 定义序保持地址序**
⇒ CRT/静态初始化序不变（重排 cpp 定义=改 init 序=禁）；ida-only 合成条目的类别源=扫描派生类别图
（data/status/global_categories.json）；删除类处置守卫强制 disposal 必填+forced-global 兜底
（语料外盲区引用会自动再生声明）。
