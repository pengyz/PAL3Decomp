# gotcha · 接线型改动：测试绿的证据力为零

**type**: gotcha
**created**: 2026-10-10
**confidence**: high（本会话 6 次实证，跨 S0/S1/S2 三任务）

## 一句话
**写了函数 + 写了测试 ≠ 接进了生产路径。** 接线型改动的唯一判据是**端到端产物数量/内容**，测试绿的证据力为 **0**。

## 症状
- 单元测试全绿（5/5、6/6、7/7）
- 但跑端到端**产物数量不变**（应收窄的没收窄）、**耗时不降**、或**静默空跑**（0.3s 就返回）

## 六次实证（同一类错误，跨三个任务）

| # | 任务 | 写了什么 | 没接什么 | 端到端症状 |
|---|---|---|---|---|
| 1 | S0 | `load_header_facts()` | 4 条决策点全没调用 | 生成头无变化 |
| 2 | S1 | `scoped_cpp_filter()` | 没接进生成循环 | 210 cpp = 210 |
| 3 | S2 | `CODEGEN_CLASS` 模块全局 | **定义在 `if __name__ == '__main__':` 之后** | NameError + 树剩 1 cpp |
| 4 | S2 | `CODEGEN_CLASS` | **无处从 `os.environ` 初始化**（`cli.py` 的 `apply_scoped_env()` 写了却从未调用）| 210 cpp = 210 |
| 5 | S2 match | `scoped_output_path()` | 写入点没调用它 | `s4_scoped*.json` 0 个 |
| 6 | S2 probe | `PROBE_ONLY` 环境变量 | **未到达子进程** | probe 0.14s 空跑、match 0 units |

## 根因模式
**「变量/函数存在，但没有从入口流到消费点」。** 尤其跨进程的环境变量通道
（`cli.py` 子进程跑 `idat`/`probe_compile`），中间任何一环没传递就断。

## 判据（必须定死，不能「看情况」）
**射程/收窄/过滤类改动的唯一完成判据 = 产物数 < 全量数。**
- ❌ 「测试绿了」——不算
- ❌ 「耗时降了」——可能是空跑（0.3s 就返回 = 什么都没做）
- ❌ 「代码看起来接好了」——不算
- ✅ **产物数量/内容的实测对比**

## 反模式（本会话全踩过）
1. **写 helper 函数不接调用点** —— 5 次
2. **模块全局默认 None 但无处赋值** —— 2 次
3. **定义在 `if __name__ == '__main__':` 之后** —— 1 次（跑时未执行）
4. **测试 import 旧的复制粘贴模块**（测的不是生产代码路径）—— 1 次
5. **端到端只看耗时不看产物数** —— 2 次（判据没定死）

## 正确做法
1. **先做「接线审计」**：画出「入口 → 中间传递 → 最终消费点」的完整链路，
   逐环节标「谁读它、谁写它」。**病灶层检查三问的第②问「消费者实际读哪个参数」
   就是这个** —— 本会话违反 6 次。
2. **一次性接完再验**，不要点状修一个验一个。
3. **端到端判据定死**：产物数 < 全量数（或内容 diff）。
4. **跨进程通道要单独验**：环境变量、文件、CLI 参数——每一跳都要实测到达。

## 附：并发写入事故（第 3 次，2026-10-12）

**R1 原文**（`data/status/_d1_ledger.md:12`）：

### 根因（第 3 次，同一模式）
| 次 | 表现 |
|---|---|
| 1 | 并行分发 3 个实现代理 ⇒ 读数互污 / `git stash` 收走 200 行 |
| 2 | `pkill` 自匹配杀自己作业 |
| **3** | **并发 codegen 互删 `pal3/src`** |

**⇒ 根因不变**：「以为不会冲突」—— 但**共享工作区就是共享写入面**。
captain 判断「codegen 是机械再生成，不算编辑」—— **错**：它写的就是 `pal3/src`，正是子代理在写的资源。

### 判据（必须机械执行）
- **任何会写 `pal3/src/`、`asm/pal3/`、`data/status/` 的操作**（codegen / export / probe / match / rmtree），
  在子代理 running 期间 **captain 一律不得跑**。
- **「机械」不是豁免理由** —— 写入面就是写入面。
- 唯一安全的 captain 操作：**只读**（grep / 读 JSON / 读生成头）+ **写 `docs/`**（零冲突）。

### 配套
- `tools/scoped_consistency_check.py` 的 `_ps_snapshot()` 已有排他窗口检查（ps 快照拦并发管线进程）
  ⇒ **captain 跑任何管线命令前应先跑它**，或至少 `ps -eo cmd | grep -E 'codegen|probe|match|idat'`。
