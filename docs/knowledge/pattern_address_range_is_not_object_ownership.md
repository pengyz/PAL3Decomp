# 地址区间≠对象存储——幻影容器/幻影成员判据体系

事实：成员"落在某全局的声称地址区间内"**不构成归属证据**。本仓实测三类幻影：
函数内 static（guard 位+atexit 空析构 thunk 四连）、池化串字面量（VC6 字符串表
"quake/bink/shock…"）、独立 g_ 全局——全部曾被 `auto:overlap_*`（凭区间重叠）或
blob 自我闭合（binary_size=成员最大偏移反推，再用它证明成员在域内）造进容器。

**为什么：** "地址区间⇒成员存在"是推理跳跃；blob 自我闭合是循环论证（CEffMgr 43312B
"精确闭合"实为串表）。证据体系（W1 裁定门实证）：**正证**=this 物化锚（`mov ecx,imm; call`）
> ctor/dtor thunk 对（`mov ecx,imm; jmp`+`push dtor; call 0x553041`）> 多函数成员形态访问；
**负证**=static 三元组侵入（test r8,imm8+jcc 保护体内写簇）> 串指纹（≥N 可打印+NUL 收尾+
仅指针实参引用，**三条件合一**）> 同址独立全局视图；**同址仲裁：A 级锚 > 区间包含**。
注意：字节落串区不单独定罪（真 char[] 成员也落串区）；"地址活"（xref 存在）不证归属。
实证基线：PAL3 91024→4936（18 倍虚高）、SceneMgr 167→145、CEffMgr 43312=纯串表、
16 类 37 条 auto:overlap 全为幻影。

**何时使用：** 任何"成员/字段/缺口"类批量改动前——先跑 tools/member_existence_gate.py
裁定（exists=地址活≠归属）；容器尺寸收缩须正向锚（static 块界/ctor 字段写/邻接符号）；
删除类改动的门禁须含**地址处置闭合**（删掉的引用有承接条目，渲染不断链）——布局等价
审计对删除无判别力（同源自证）。多实例类按 (类,实例基址) 双键取证，禁类级套实例。
